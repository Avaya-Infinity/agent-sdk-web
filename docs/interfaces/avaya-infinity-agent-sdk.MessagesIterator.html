    Interface MessagesIterator

    Iterator for the message history of an interaction.

    • previous fetches older messages.
    • next fetches newer messages.

    The first call to previous or next - returns the most recent batch of messages and seeds the iterator from there. From that starting point, previous pages backward into older history and next fetches any newer messages that have since arrived.

    Concurrent calls to next / previous are serialized - they never run in parallel.

    Example

    const iter = interaction.getMessages({ pageSize: 50 });
    let batch = await iter.previous();
    while (iter.hasPrevious()) {
        batch = await iter.previous();
    }
    interface MessagesIterator {
        hasNext(): boolean;
        hasPrevious(): boolean;
        next(): Promise<Message[]>;
        previous(): Promise<Message[]>;
    }
