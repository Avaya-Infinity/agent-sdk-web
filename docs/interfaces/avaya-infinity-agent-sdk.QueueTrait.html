    Interface QueueTrait

    Contract implemented by Queue that describes the full API surface for queue management.

    Covers queue identity, login state, and the login/logout lifecycle. Consume this interface when referencing the Queue API shape without coupling to the concrete Queue class (e.g. in test doubles or adapters).

    queueId

    queueId: string

    The unique identifier of the queue.

    queueName

    queueName: string

    The display name of the queue as configured in the contact center platform.

    queueType

    queueType: QueueType

    The category of the queue.

    GENERAL and HYBRID queues support explicit login / logout; PERSONAL queues do not — the platform manages them automatically. UNKNOWN indicates the backend did not send the type field (typically an older backend version); the SDK does not gate login/logout for UNKNOWN — any server-side restriction surfaces via the server's rejection response instead.

    isLoggedIn

    isLoggedIn: boolean

    Methods

    canLogin

    • canLogin(): boolean

      Whether the agent can log into this queue right now.

      Returns true when the platform rules allow login (e.g. the agent is logged into CX, has access to the queue, and is not already logged in). Returns false otherwise.

      Returns boolean

    login

    • login(): Promise<void>

      Logs the agent into this queue so the platform can start routing interactions to them.

      Returns Promise<void>

      A promise that resolves when the agent is successfully logged into the queue.

      Throws

      AvayaInfinityAgentSdkError If the login request fails.

    canLogout

    • canLogout(): boolean

      Whether the agent can log out of this queue right now.

      Returns true when the platform rules allow logout (e.g. the agent is logged into CX, has access to the queue, and is currently logged in). Returns false otherwise.

      Returns boolean

    logout

    • logout(reasonCode: ReasonCode): Promise<void>

      Logs the agent out of this queue so the platform stops routing interactions to them.

      The reasonCode must be a ReasonCode with type LOGOUT from User.getAssignableReasonCodes.

      Parameters

      • reasonCode: ReasonCode

        The logout reason code. Must have type equal to ReasonType.LOGOUT.

      Returns Promise<void>

      A promise that resolves when the agent is successfully logged out of the queue.

      Throws

      AvayaInfinityAgentSdkError If the logout request fails.
