    Connection health snapshot at export time. Contains cumulative counters for the WebSocket connection and the WebRTC voice channel, plus the page-session uptime. Values survive init()/destroy() cycles and reset only on page reload.

    Type Declaration

    • ws: SdkWsMetrics

      WebSocket connection counters — see SdkWsMetrics.

    • webRtcRegistration: SdkWebRtcRegistrationMetrics

      WebRTC registration counters — see SdkWebRtcRegistrationMetrics.

    • voice: SdkVoiceMetrics

      Voice call failure records and counters — see SdkVoiceMetrics.

    • sessionStartedAt: number

      Epoch-ms timestamp when the SDK module was first loaded in this browser tab.

    • sessionUptimeMs: number

      Wall-clock milliseconds since sessionStartedAt, computed at snapshot time.

    entries

    entries: SdkLogEntry[]

    Captured log entries in chronological order (oldest first).
