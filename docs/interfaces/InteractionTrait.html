    Interface InteractionTrait

    Contract implemented by Interaction that describes the full API surface for managing a contact center interaction. Covers the complete lifecycle from acceptance through wrap-up, as well as call controls, transfer operations, conference management, viewer controls, event subscriptions, and interaction metadata.

    Consume this interface when you need to reference the Interaction API shape without coupling to the concrete Interaction class (e.g., in test doubles or adapters).

    ReadonlyisElite

    isElite: boolean

    Whether this interaction is routed through Avaya Elite Voice. Set at interaction creation and does not change during the interaction.

    ReadonlyengagementId

    engagementId: string

    Identifier shared by interactions that belong to the same customer journey (e.g. an inbound call followed by a callback). Use this to link related interactions in CRM integrations. Stable for the lifetime of the interaction.

    ReadonlyinitialCommunicationType

    initialCommunicationType: InteractionCommType

    The channel the interaction started on. Immutable - does not change even if the interaction's current communicationType switches later (e.g. a chat escalated to a voice call).

    ReadonlyinitialCommunicationSubType

    initialCommunicationSubType: InteractionCommSubType

    The sub-communication type the interaction started with. Values are channel-specific. Immutable for the lifetime of the interaction.

    Optional ReadonlyendTime

    endTime?: Date

    When the interaction finished wrap-up. undefined while the interaction is still active or in wrap-up.

    ReadonlyroutingDetails

    routingDetails: RoutingDetails

    Routing context for the interaction. Empty string means "not populated".

    Optional ReadonlyownerDetails

    ownerDetails?: OwnerDetails

    Identity of the agent currently owning this interaction. Complements isOwner (which only tells you whether you are the owner). undefined when no agent is assigned yet.

    subject

    subject: string

    The subject or title of the interaction.

    notes

    notes: string

    Notes associated with the interaction.

    customFields

    customFields: Record<string, unknown>

    Custom key/value data persisted on the interaction.

    Update via mergeCustomFields (it deep-merges; keys not mentioned are preserved).

    Monitoring

    barge

    • barge(): Promise<void>

      Barges into the call as an Elite supervisor - the supervisor's voice becomes audible to both the agent and the customer. Resolves once the server confirms the mode transition; rejects on request failure or after a 30s timeout.

      Returns Promise<void>

      Throws

      When canBarge returns false

    unbarge

    • unbarge(): Promise<void>

      Stops barging and returns the supervisor to listen-only (mic silenced). Same async confirmation pattern as barge.

      Returns Promise<void>

      Throws

      When canUnbarge returns false

    coach

    • coach(): Promise<void>

      Starts coaching as an Elite supervisor - the supervisor's voice reaches only the agent (whisper coaching); the customer does not hear it. Resolves once the server confirms the mode transition; rejects on request failure or after a 30s timeout.

      There is no explicit "uncoach" - leave the call via leaveCall to exit coach mode.

      Returns Promise<void>

      Throws

      When canCoach returns false

    claimOwnership

    • claimOwnership(): Promise<void>

      Returns Promise<void>
