    Interface TransferableUser

    An agent who can receive a transferred call.

    Returned in pages by Interaction.getTransferableUsers. Use eligible to filter agents who can actually accept the transfer, and isLoggedInToCx to check whether the agent is currently active. Pass userId in BlindTransferToUserOptions or AttendedTransferToUserOptions to initiate the transfer.

    Example

    const page = await interaction.getTransferableUsers({ page: 1, name: "John" });
    const target = page.users.find(u => u.eligible && u.isLoggedInToCx);
    if (target) {
      await interaction.blindTransfer({ userId: target.userId });
    }
