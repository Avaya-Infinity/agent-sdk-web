    Interface ViewerTrait

    Contract implemented by Viewer that describes the API surface for an owner acting on another viewer of an interaction. Consume this interface when you need to reference the Viewer API shape without coupling to the concrete class (e.g. in test doubles).

    Status

    Optional ReadonlyisAudio

    isAudio?: boolean

    Whether the viewer has joined the audio call. undefined for interactions where audio does not apply (e.g. non-voice channels) or before the viewer record exists.

    Optional ReadonlyisMuted

    isMuted?: boolean

    Optional ReadonlyeliteSupervisorMode

    eliteSupervisorMode?: EliteSupervisorMode

    Elite supervisor monitoring mode. Only set for Elite supervisor viewers (viewerType === "eliteSupervisor") that have joined audio. undefined otherwise.
