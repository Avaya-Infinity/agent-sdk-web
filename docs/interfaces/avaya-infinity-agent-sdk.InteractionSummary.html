    Interface InteractionSummary

    A read-only snapshot of an interaction, returned by InteractionView.getInteractions.

    Contains enough information to identify, inspect, and select an interaction.

    See

    • InteractionView.getInteractions
    • InteractionSummaryPage
    interface InteractionSummary {

        currentStatus: InteractionStatus;
        communicationType: InteractionCommType;
        communicationSubType: InteractionCommSubType;
        startTime: string;
        isElite: boolean;
        queueDetails: { queueId: string; name: string };
        user: {

    Properties

    interactionId

    interactionId: string

    The unique interaction identifier. Pass this to User.viewInteraction.

    currentStatus

    currentStatus: InteractionStatus

    The current interaction status.

    communicationType

    communicationType: InteractionCommType

    The communication type.

    communicationSubType

    communicationSubType: InteractionCommSubType

    The sub-communication type (direction).

    startTime

    startTime: string

    ISO 8601 timestamp when the interaction started (or createdOn if startTime is null).

    isElite

    isElite: boolean

    Whether this is an elite (hybrid) interaction.

    queueDetails

    queueDetails: { queueId: string; name: string }

    The queue this interaction is assigned to.

    user

    user: {
        id: string;
        firstName: string;
        lastName: string;
        fullName: string;
        email: string;
    }

    The agent owning this interaction.

    sourceDetails

    sourceDetails: { name: string; phoneNumber: string }

    The customer's contact details. Empty strings when not available.

    subject

    subject: string

    The interaction subject (e.g. "New Phone Inbound"). Empty string when not set.

    route

    route: { name: string; phoneNumber: string }

    The routing target used by the customer to reach the queue.

    tags

    tags: string[]

    Tag names attached to the interaction.

    isAid

    isAid: boolean

    Whether this interaction has an Active Interaction Distribution (AID) signal from the platform.

    viewerCount

    viewerCount: number

    The number of viewers currently on this interaction.
