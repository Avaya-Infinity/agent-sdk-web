    Interface TransferDetails

    Details of an in-progress or completed transfer on an interaction.

    Available from Interaction.transferDetails when a blind or attended transfer has been initiated. Use these fields to determine what transfer controls to surface in the UI and to identify the consulted party.

    Example

    const details = interaction.transferDetails;
    if (details) {
        console.log("Transfer type:", details.transferType); // "blind" | "attended"
    }

    isExternalTransfer?: boolean

    Whether the active transfer targets an external (PSTN) phone number. Absent or false for internal (agent / queue) transfers.

    externalTransferTo?: string

    The external phone number being transferred to. Populated only when isExternalTransfer is true; undefined otherwise.
