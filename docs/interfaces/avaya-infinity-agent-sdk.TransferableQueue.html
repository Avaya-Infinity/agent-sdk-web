    Interface TransferableQueue

    A queue eligible to receive a transferred call.

    Returned in pages by Interaction.getTransferableQueues. Use eligible to filter queues that can accept the transfer. The load metrics (waitingInteractions, countActiveAgents) help the agent choose the most appropriate queue. Pass queueId and name in BlindTransferToQueueOptions or AttendedTransferToQueueOptions to initiate.

    Example

    const page = await interaction.getTransferableQueues({ page: 1, name: "Billing" });
    const target = page.queues.find(q => q.eligible);
    if (target) {
      await interaction.blindTransfer({ queueId: target.queueId, queueName: target.name });
    }

    Properties

    queueId

    queueId: string

    The unique identifier of the queue. Pass this as queueId in transfer options.

    name

    name: string

    The display name of the queue. Pass this as queueName in transfer options.

    eligible

    eligible: boolean

    Whether this queue can receive the transfer. false if the queue has no available agents or is otherwise unable to accept transfers.

    totalCurrentInteractions

    totalCurrentInteractions: number

    The total number of interactions currently in the queue (waiting + connected).

    waitingInteractions

    waitingInteractions: number

    The number of interactions currently waiting to be answered.

    connectedInteractions

    connectedInteractions: number

    The number of interactions currently connected to an agent.

    countActiveAgents

    countActiveAgents: number

    The number of agents currently logged into and active on this queue.
