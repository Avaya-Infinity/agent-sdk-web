    Enumeration WebRtcRegistrationState

    The registration state of the agent's WebRTC voice channel with the media server.

    The SDK must successfully register before the agent can participate in voice interactions. Subscribe to WebRtcRegistrationEventType events to track transitions, and call User.getWebRtcRegistrationState to read the current state.

    Example

    const status = user.getWebRtcRegistrationState();
    if (status === WebRtcRegistrationState.REGISTERED) {
      console.log("Voice channel ready");
    }
