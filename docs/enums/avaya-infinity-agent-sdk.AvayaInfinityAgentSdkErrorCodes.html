    Enumeration AvayaInfinityAgentSdkErrorCodes

    Public catalog of error codes emitted by the Avaya Infinity Agent SDK.

    Compare an AvayaInfinityAgentSdkError.code value with an enum member instead of hard-coding the error-code string.

    Format ASE-XYYY where X is the family code prefix and YYY is the error code Where X is one of the following:

    • 0: Generic errors
    • 1: SDK level errors
    • 2: User level errors
    • 3: Queue level errors
    • 4: Interaction level errors

    Example

    if (
      AvayaInfinityAgentSdkError.is(error)
      && error.code === AvayaInfinityAgentSdkErrorCodes.ASE_1003
    ) {
      showBanner("Please allow popups and try again");
    }
