    Enumeration InteractionStatus

    The lifecycle state of an interaction.

    States progress sequentially from PENDING through CONNECTED to WRAP_UP and finally COMPLETED. Intermediate states (HOLD, BLIND_TRANSFER, ATTENDED_TRANSFER) indicate transient call conditions. The platform sets the state; read it from Interaction.currentStatus.

    Example

    interaction.subscribe(InteractionEventType.INTERACTION_WRAP_UP, () => {
        console.log("Status is now:", interaction.currentStatus); // InteractionStatus.WRAP_UP
    });

    Enumeration Members

    PENDING

    PENDING: "pending"

    The interaction has arrived and is ringing for the agent. The platform sets this state when the interaction is distributed to the agent but has not yet been accepted.

    CONNECTED

    CONNECTED: "connected"

    The agent has accepted the interaction and is actively connected to the customer. The platform sets this state immediately after a successful Interaction.accept call.

    WRAP_UP

    WRAP_UP: "wrapUp"

    The interaction has ended and the agent is completing post-call work (wrap-up). The platform sets this state after the call is disconnected. The agent can record notes and set classification codes before closing the interaction.

    COMPLETED

    COMPLETED: "completed"

    The interaction has been closed and all wrap-up work is finalized. The platform sets this terminal state after a successful Interaction.close or Interaction.complete call.

    UNKNOWN

    UNKNOWN: "unknown"

    The interaction state could not be determined. The platform sets this state when the received status value does not match any known state.

    HOLD

    HOLD: "hold"

    The customer call is currently on hold. The platform sets this state after a successful Interaction.holdCall call.

    BLIND_TRANSFER

    BLIND_TRANSFER: "blindTransfer"

    A blind (immediate, no-consultation) transfer is in progress. The platform sets this state briefly while routing the call to the target agent or queue.

    ATTENDED_TRANSFER

    ATTENDED_TRANSFER: "attendedTransfer"

    An attended (consultative) transfer is in progress. The platform sets this state after a successful Interaction.attendedTransfer call, while the agent is consulting with the target before handing off the customer.
