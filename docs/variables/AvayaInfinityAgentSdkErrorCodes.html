    Public facing error codes Format ASE-XYYY where X is the family code prefix and YYY is the error code Where X is one of the following:

    • 0: Generic errors
    • 1: SDK level errors
    • 2: User level errors
    • 3: Queue level errors
    • 4: Interaction level errors

    Note: ASE-0000 is reserved. Don't use it.
