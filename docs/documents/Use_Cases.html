    Use Cases

    The Avaya Infinity™ Agent SDK capabilities are organized into the functional groups below. Each sub-item links to the relevant section of the detailed guides. Sub-items prefixed with (Elite) apply only to Elite (hybrid) deployments. For now, the Agent SDK supports voice interactions only.

    Before You Begin

    Note

    This documentation assumes working familiarity with Avaya Infinity™ terminology (see the Avaya Infinity documentation) and with the voice domain. Get comfortable with both before working through the use cases.

    Note

    The code samples in these guides are illustrative and focus on the SDK API being demonstrated. For brevity they omit production concerns - logging, input validation, error handling, and handler cleanup (unsubscribing). Integrators are responsible for adding these.

    Handling failures: Every asynchronous SDK action returns a promise that rejects with an AvayaInfinityAgentSdkError when the operation fails. Always handle the rejection - either await the action inside a try/catch, or attach a .catch() handler:

    try {
      await interaction.accept();
    } catch (err) {
      // err is an AvayaInfinityAgentSdkError - inspect err.code to decide how to react
      showError(err);
    }

    // Without await, use the .catch() pattern instead:
    interaction.reject().catch((err) => showError(err));
