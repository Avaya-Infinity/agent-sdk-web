    Class Queue

    Represents a queue assigned to the agent for receiving interactions.

    Obtained from User.getAssignedQueues or refreshed via User.refreshAssignedQueues. An agent must log into a queue before the platform routes interactions to them from it. Multiple queues can be logged into simultaneously.

    Typical usage

    1. Retrieve assigned queues via User.getAssignedQueues.
    2. Check isLoggedIn to determine the current login state for each queue.
    3. Call login to start receiving interactions from a queue.
    4. Call logout with a ReasonCode of type LOGOUT when the agent is done.

    Example

    const queues = user.getAssignedQueues();
    const queue = queues.find(q => q.queueName === "Support");

    if (queue && !queue.isLoggedIn) {
      await queue.login();
      console.log("Logged into:", queue.queueName, "at", queue.loggedInAt);
    }

    // Log out with a logout reason code
    const reasons = await user.getAssignableReasonCodes();
    const logoutReason = reasons.find(r => r.type === ReasonType.LOGOUT);
    if (logoutReason) {
      await queue.logout(logoutReason);
    }

    Actions

    canLogin

    • canLogin(): boolean

      Whether the agent can log into this queue right now.

      Returns true when the platform rules allow login (e.g. the agent is logged into CX, has access to the queue, and is not already logged in). Returns false otherwise.

      Returns boolean

      Example

      if (queue.canLogin()) {
        await queue.login();
      }

    canLogout

    • canLogout(): boolean

      Whether the agent can log out of this queue right now.

      Returns true when the platform rules allow logout (e.g. the agent is logged into CX, has access to the queue, and is currently logged in). Returns false otherwise.

      Returns boolean

      Example

      if (queue.canLogout()) {
        const reasons = await user.getAssignableReasonCodes();
        const logoutReason = reasons.find(r => r.type === ReasonType.LOGOUT);
        if (logoutReason) await queue.logout(logoutReason);
      }

    queueType

    • get queueType(): QueueType

      The category of the queue.

      GENERAL and HYBRID queues support explicit login / logout; PERSONAL queues do not — the platform manages them automatically. UNKNOWN indicates the backend did not send the type field (typically an older backend version); the SDK does not gate login/logout for UNKNOWN — any server-side restriction surfaces via the server's rejection response instead.

      Returns QueueType

      Example

      const loggable = user.getAssignedQueues()
        .filter(q => q.queueType !== QueueType.PERSONAL);
