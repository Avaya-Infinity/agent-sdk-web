    Class InteractionView

    Represents a server-side interaction view filter.

    Views define preset filters for the interaction list (e.g., "All Active Interactions"). Obtained from User.getInteractionViews; call getInteractions on the view to fetch the interactions it surfaces.

      Fetches a page of interactions filtered by this view.

      Parameters

      • Optionalparams: GetInteractionsParams

        Optional pagination parameters. pageSize is clamped to [1, 50].

      A promise that resolves to a page of InteractionSummary.
