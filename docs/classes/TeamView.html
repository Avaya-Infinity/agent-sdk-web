    Class TeamView

    A team view (group) containing the team members and their current state.

    Obtained from User.getTeamViewById. Call refresh on the returned object to reload its data from the server.

    Example

    const teams = user.getAssignedTeamViews();
    const teamView = await user.getTeamViewById(teams[0].teamViewId);
    for (const member of teamView.members) {
        console.log(member.userFullName, member.currentStatus.reason);
    }
    // Reload later
    await teamView.refresh();

    refresh

    • refresh(): Promise<void>

      Reloads the team view from the server, updating name, members, and lastSyncedAt on this object.

      Existing references to this TeamView see the updated data after the promise resolves. If the request fails, the data on this object is unchanged.

      Returns Promise<void>

      A promise that resolves when the team view has been reloaded

      Throws

      If the team view no longer exists (code ASE-2018)

      Throws

      If the request fails (code ASE-2017)

      Example

      await teamView.refresh();
      console.log("Updated members:", teamView.members.length);
